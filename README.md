# MOHAMED.CONTROL

موقع تعليمي عربي عن كاميرات المراقبة وغرف التحكم ومهام مراقب الكاميرات، مع تركيز على العمل في المولات التجارية.

## رابط الموقع

الموقع منشور عبر GitHub Pages من هذا المستودع. افتح صفحة **Settings ← Pages** لمعرفة الرابط الحالي.

## إزاي تعدّل الموقع بنفسك (من غير برامج)

كل محتوى الموقع موجود في ملف واحد اسمه `index.html`. التعديل كله يتم من المتصفح:

1. افتح المستودع على GitHub وسجّل دخولك.
2. اضغط على ملف `index.html`.
3. اضغط علامة القلم ✏️ (Edit this file) فوق على الشمال.
4. عدّل النص العربي اللي تحبه. أمثلة:
   - **تغيير عنوان قسم:** دوّر على نص العنوان زي `أنواع كاميرات المراقبة` وغيّره.
   - **تعديل شرح:** النصوص جوّه وسوم زي `<p>...</p>` أو `<li>...</li>`. غيّر الكلام اللي بينهم بس، وسيب الوسوم زي ما هي.
   - **إضافة نقطة جديدة لقائمة:** انسخ سطر كامل يبدأ بـ `<li>` وينتهي بـ `</li>` والصقه تحت أخوه، وغيّر كلامه.
5. لما تخلص، انزل تحت واضغط الزر الأخضر **Commit changes** مرتين.
6. استنى دقيقة أو اتنين وافتح رابط الموقع، هتلاقي تعديلك ظهر.

> لو حصل غلط، GitHub بيحتفظ بنسخة من كل تعديل (History)، فتقدر ترجع لأي نسخة قديمة.

## حاجات متعملهاش

- متكتبش بيانات شخصية أو باسوردات جوّه الملفات، المستودع عام وأي حد يقدر يشوفه.
- متغيّرش اسم ملف `index.html` ولا تنقله من مكانه، الرابط بيعتمد عليه.

## تنبيه

المحتوى تعليمي عام، مش بديل عن التدريب المعتمد أو خطة الطوارئ الرسمية لأي موقع.
