# MOHAMED.CONTROL

موقع تعليمي عربي عن كاميرات المراقبة وغرف التحكم ومهام مراقب الكاميرات، مع تركيز على العمل في المولات التجارية.

عنوان الصفحة الرئيسية: **كيف تصبح مراقب كاميرات ناجح**

## رابط الموقع

الموقع منشور عبر GitHub Pages من هذا المستودع. افتح صفحة **Settings ← Pages** لمعرفة الرابط الحالي. الرابط لم يتغير.

## ملفات الموقع

الموقع صفحة رئيسية و12 صفحة موضوعات، كل صفحة في ملف مستقل:

| الملف | الموضوع |
|---|---|
| `index.html` | الصفحة الرئيسية ومسار التعلم |
| `cameras.html` | أنواع الكاميرات |
| `specs.html` | المواصفات الفنية |
| `control-room.html` | غرفة المراقبة |
| `duties.html` | مهام المراقب |
| `malls.html` | المراقبة في المولات |
| `incident.html` | خطوات التعامل مع الحدث |
| `scenarios.html` | سيناريوهات عملية |
| `training.html` | التدريب والمهارات |
| `growth.html` | التطور المهني |
| `mistakes.html` | أخطاء شائعة |
| `terms.html` | المصطلحات |
| `sources.html` | المصادر |
| `style.css` | التصميم المشترك لكل الصفحات |
| `app.js` | قائمة الموبايل والساعة وحركة الظهور |

الرسومات التوضيحية مكتوبة داخل ملفات الصفحات نفسها (SVG)، فلا توجد ملفات صور منفصلة.

## إزاي تعدّل الموقع بنفسك (من غير برامج)

1. افتح المستودع على GitHub وسجّل دخولك.
2. اضغط على ملف الصفحة اللي عايز تعدّلها (مثلاً `mistakes.html` لصفحة الأخطاء الشائعة).
3. اضغط علامة القلم ✏️ (Edit this file) فوق على الشمال.
4. عدّل النص العربي. النصوص جوّه وسوم زي `<p>...</p>` أو `<li>...</li>`. غيّر الكلام اللي بينهم بس، وسيب الوسوم زي ما هي.
5. لإضافة نقطة جديدة لقائمة: انسخ سطر كامل يبدأ بـ `<li>` وينتهي بـ `</li>` والصقه تحت أخوه.
6. لتغيير الألوان أو الخطوط في كل الصفحات مرة واحدة: عدّل `style.css`.
7. اضغط الزر الأخضر **Commit changes** مرتين.
8. استنى دقيقة أو اتنين وافتح الرابط، هتلاقي تعديلك ظهر. لو الموبايل لسه بيعرض القديم، اعمل تحديث للصفحة.

> لو حصل غلط، GitHub بيحتفظ بنسخة من كل تعديل (History)، فتقدر ترجع لأي نسخة قديمة.

## حاجات متعملهاش

- متكتبش بيانات شخصية أو باسوردات جوّه الملفات، المستودع عام وأي حد يقدر يشوفه.
- متغيّرش أسماء الملفات ولا تنقلها من مكانها، لأن الصفحات بتربط ببعض بالأسماء دي.

## تنبيه

المحتوى تعليمي عام وليس بديلاً عن التدريب المعتمد أو القوانين وسياسات مكان عملك. الرسومات توضيحية وليست كاميرات حقيقية.
